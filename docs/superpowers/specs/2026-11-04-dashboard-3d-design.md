# Объёмный граф дашборда

Запрос: заменить плоский граф объёмным, используя Three.js, силовую раскладку,
OrbitControls и подписи three-spritetext.

Дашборд остаётся одним автономным HTML-файлом. Вместо React-обёртки используем
её основу `3d-force-graph`, поскольку существующий интерфейс написан на обычном
JavaScript. Альтернативы — внедрить React только ради графа или написать свою
3D-физику — добавляют лишнюю поддержку. Зависимости закрепляются lock-файлом,
собираются локально и встраиваются в HTML; CDN не требуется.

3D становится основным видом. Проекты — крупные сферы с оболочкой, записи —
малые сферы цвета источника. d3-force-3d рассчитывает все три координаты;
OrbitControls вращает и приближает камеру. Подписи SpriteText смотрят на камеру;
по умолчанию видны проекты и выбранные записи, дополнительные подписи появляются
при приближении. «Области проектов» включает полупрозрачные объёмные оболочки.

Сохраняются фильтры, поиск, выделение соседей, карточки, второй клик для открытия,
режим окрестности, вписывание, полноэкранный режим и клавиатура. Камера учитывает
панель выбранной записи. 3D-координаты хранятся отдельно от прежней 2D-раскладки.
Скрытая вкладка приостанавливает WebGL. Reduced motion отключает перелёты.
При отсутствии WebGL используется прежний canvas-граф с пояснением.

Проверка: сборка одного HTML, существующие Python-тесты, офлайн-открытие в браузере,
физика по z, вращение/масштаб, поиск и выбор, фильтры, окрестность, темы,
узкий экран, восстановление раскладки и fallback без WebGL.
