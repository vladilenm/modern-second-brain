# Панель базы: обзор, граф, проекты, записи

Дата: 2026-10-28. Переделка `brain dashboard`: сейчас это одна длинная страница с таблицами, которую не хочется
листать. Нужна панель, по которой с первого взгляда видно, что лежит в базе и что происходит, плюс граф связей
как в Obsidian.

## Что решено

- Снимок, как сейчас: `brain dashboard` собирает один `data/dashboard.html`, данные вшиты, сервера нет, права 600.
- Без внешних скриптов: графики в SVG, граф на canvas, всё своё. Внешние только шрифты Google Fonts (как сейчас),
  при отсутствии сети страница работает на системных шрифтах.
- Четыре вкладки: **Обзор**, **Граф**, **Проекты**, **Записи** (записи и здоровье базы на одной вкладке).
  Разделов «Знания» и «Ритм работы» нет; атомы видны только как плитка на обзоре и блок на странице проекта.
- Граф: узлы — записи и проекты-хабы; связи — запись → проект и запись ↔ похожие записи по общим темам.
- Проекты склеиваются по имени: локальная папка и репозиторий GitHub с одним именем — один проект.
- Стиль — дизайн-система Владилена Минина 1.0.0 (токены как в текущей панели, тёмное боковое меню `side-*`).
  Палитры графиков в системе нет (Known Gaps), поэтому цвета источников заводятся в панели локальными токенами
  `--series-1…4` с комментарием; перенос в `tokens.mjs` системы — отдельная правка в её репозитории.

  ChatGPT 0. У всех есть карточки. GitHub с ноября 2024, разговоры с сентября 2026.
- 90 разных значений `project`, пустых нет. Одни и те же проекты встречаются дважды:
  `~/Documents/vscode/club-landing` (13) и `vladilenm/club_landing` (9), `~/Documents/dev/tg-parser-digest` (3)
  и `vladilenm/tg-parser-digest` (4).
- Атомы в карточках: fact 1271, decision 274, fix 269, command 233, todo 227, error 35.
- Ключевые слова: 4978 разных, в 2+ записях — 1083, в 10+ — 63. Шум: формы одного слова («рилс», «рилса»,
  «рилсу»), даты («2026-10-19», «19 октября 2026»), имена файлов (`final.mp4`, `lessons.md`), слишком общие
  темы («claude code» в 96 записях из 336).
- Наивная связь «3+ общих ключевых слова» даёт 1609 пар — слишком густо, нужен TF-IDF и отбор соседей.
- Текущий `data/dashboard.html` весит 2,7 МБ, почти всё — начала расшифровок (6000 символов на запись).

## Подходы

- **A (выбран).** Снимок без сервера, своя отрисовка без библиотек; связи графа и склейку проектов считает
  Python при сборке. Ни сервера, ни чужого JavaScript в странице с личными данными, работает офлайн, в духе
  проекта «без зависимостей». Цена — больше своего кода.
- B. Снимок плюс D3 / force-graph с CDN. Быстрее собрать, но страница с переписками тянет скрипты из интернета
  и без сети не открывается. Отброшен.
- C. Локальный сервер `brain dashboard --serve` с живыми данными и поиском BM25. Долгоживущий процесс
  противоречит схеме «запустился — сделал — завершился». Отложен, можно сделать отдельно.

## Каркас

- Слева тёмное боковое меню (`side-bg`, `side-ink`, `side-muted`, `side-active`): название, вкладки Обзор, Граф,
  Проекты, Записи; внизу состояние — время последней синхронизации, «пересказываю 12 из 40», если идёт прогон,
  и ошибки источников (`GitHub: нет связи…`). Пункт активной вкладки — `side-active`.
- Адреса вкладок: `#overview` (по умолчанию), `#graph`, `#graph/<id>` (граф с выделенной записью), `#projects`,
  `#project/<ключ>`, `#records`. Назад/вперёд в браузере работают. «Открыть базу» в значке открывает обзор.
- Уже 1024px (брейкпоинт `lg` системы) меню прячется: сверху полоса с названием, текущей вкладкой, точкой
  состояния и кнопкой меню; меню выезжает слева поверх страницы.
- Быстрый поиск в меню (клавиша `/`): до 10 совпадений по названию, проекту, ключевым словам и пересказу,
  все слова запроса должны найтись (как фильтр сейчас). Enter или клик открывает карточку записи.
- Карточка записи — выезжающая справа панель, общая для всех вкладок (как сейчас: мета, пересказ, атомы,
  вопросы, ключевые слова, начало расшифровки) плюс «Похожие записи» (соседи из графа, до 5) и кнопка
  «Показать на графе». `Esc` закрывает, фокус возвращается.

## Обзор

- Плитки (KPI-ряд):
  - **Записей** — всего; подпись «N активных за 7 дней» (по `updated_at`) и разбивка по источникам.
  - **Проектов** — после склейки; подпись «N живых за 30 дней» (есть запись с `updated_at` за 30 дней).
  - **Знаний** — число атомов в карточках; подпись — три самых частых типа, кроме `fact`
    («274 решения · 269 исправлений · 227 задач»).
  - **Карточки** — доля записей с карточкой, полоса 6px; подпись — очередь пересказа или ошибки пересказа.
- **Записи по неделям** — столбцы, сложенные по источникам в порядке слотов палитры, переключатель
  «3 месяца / год / всё». 3 месяца и год — по неделям (понедельник — начало), «всё» — по месяцам. Подпись над
  пиком и последним столбцом, подсказка при наведении: период, всего и по источникам. Легенда над графиком.
- **Где больше всего работы** — первые 8 проектов по числу записей, горизонтальные полосы одним цветом
  (сравнение величин, не источников). Клик — страница проекта.
- **Свежее** — 6 последних записей: точка источника, название, проект, дата. Клик — карточка.

## Граф

- Узлы:
  - запись — круг цвета источника, радиус от 3 до 9px по `log(body_len)`;
  - проект — круг-кольцо в цвете `ink-muted`, радиус от 6 до 16px по `sqrt(записей)`.
- Рёбра:
  - запись → её проект: 1px, `line`;
  - запись ↔ похожая запись: 1px, `line-strong`, прозрачность по силе сходства (0,25–0,8).
- Раскладка — своя физика: отталкивание узлов, пружины рёбер (проектные короче), слабое притяжение к центру,
  затухание. До 600 узлов отталкивание считается попарно, больше — через квадродерево (Barnes-Hut).
  Около 300 шагов; анимация видна, при `prefers-reduced-motion` раскладка считается сразу.
- Управление: колесо и щипок — масштаб, перетаскивание фона — сдвиг, перетаскивание узла двигает узел,
  кнопки «+», «−», «вписать». Наведение на запись: она, её проект и соседи остаются яркими, остальное гаснет,
  подсказка — название, проект, дата. Клик по записи — карточка, клик по проекту — `#project/<ключ>`.
- Над графом одна строка фильтров: чипы источников (они же легенда, с числом записей), период
  «всё / 90 дней / 30 дней», переключатель «связи по темам», поле «найти на графе» (подсвечивает совпадения).
  Скрытые фильтром узлы не участвуют в отрисовке, но раскладка не пересчитывается — картина не прыгает.
- Подписи: проекты с 5+ записями подписаны всегда, остальные проекты — при масштабе от 1,5, записи — от 2,5.
- Canvas учитывает `devicePixelRatio`, перерисовывается только при движении или взаимодействии.
- `aria-label` холста — сводка («N записей, M проектов, K связей по темам»); те же данные доступны списком
  на вкладках «Проекты» и «Записи».

## Проекты

- Сетка карточек (`card`, 10px): имя проекта; откуда собран — пути и репозитории моноширинным `body-sm`;
  число записей; тонкая полоса долей по источникам; мини-график записей за 12 недель (столбики 4px, один цвет);
  дата последней записи; до 5 главных тем тегами.
- Главные темы проекта: темы его записей, отсортированные по «сколько записей проекта с темой × idf темы».
- Сортировка: «недавние» (по последней записи, по умолчанию) и «больше записей»; фильтр по названию и пути.
- Страница проекта `#project/<ключ>`: хлебная крошка «Проекты / имя», цифры (записей, по источникам, первая
  и последняя дата), блок «Решения и задачи» — последние 10 атомов `decision` и `todo` из карточек проекта
  с переходом в карточку записи, лента записей проекта по месяцам (как строки на вкладке «Записи»).

## Записи и здоровье базы

- Сверху — источники компактными строками: название с точкой цвета; статус-тег «ок» / «ошибка» /
  «не запускалась» и текст ошибки; «синхронизация N мин назад»; записей; без карточки; ещё идут; пропущено.
  У источника без записей и с `hint` — подсказка вместо цифр. Пояснение «ещё идут» и «пропущено» — как сейчас,
  одной строкой под блоком. Рядом — очередь пересказа: сколько без карточки и сколько синхронизаций её разберут.
- Ниже — лента записей: поиск, сегменты «источник» и «статус» (как сейчас). Записи сгруппированы по дням
  `updated_at`: «Сегодня», «Вчера», «27 октября» (с годом, если не текущий). Строка: точка источника, название,
  одна строка пересказа, проект моноширинным, тег статуса только если карточки нет. Сначала 100 строк,
  дальше кнопка «Показать ещё 100». Счётчик «Найдено N из M».

## Данные

### `brain/topics.py` (новый, стандартная библиотека)

- `normalize(keyword) -> Optional[str]` — ключ темы или `None`:
  - нижний регистр, `ё`→`е`, пробелы схлопнуты;
  - `None` для дат (`2026-10-19`, `19 октября 2026`, `октябрь 2026`), чисел и размеров (`1080×1920`),
    имён файлов (одно слово с расширением 1–5 символов: `final.mp4`, `lessons.md`), короче 3 символов;
  - каждое слово сводится к основе: кириллическое длиннее 4 букв теряет одно окончание из списка (длинные
    первыми: `ами ями ого его ому ему ыми ими ов ев ей ой ий ый ая яя ое ее ые ие ом ем ах ях ам ям а я ы и у ю е о`),
    латинское длиннее 4 букв теряет конечную `s` (не `ss`).
- `record_topics(keywords, title) -> list[(ключ, исходная форма)]` — темы из ключевых слов карточки; если их нет
  (короткая запись без карточки), из слов названия длиннее 3 букв без стоп-слов.
- `build(records) -> Topics` по всем записям:
  - `df` темы — в скольких записях; темы с `df < 2` и `df > 25%` записей (при 20+ записях) не участвуют
    в сходстве;
  - отображаемая форма темы — самая частая исходная форма;
  - `record_topics[id]` — до 8 отображаемых тем записи по убыванию idf (для карточек проектов);
  - `neighbors[id]` — собственный выбор записи: до 3 соседей со сходством не ниже `MIN_SIM`, по убыванию.
    Вектор записи — бинарный TF × idf (`log(N/df)`), сходство — косинус; кандидаты только через обратный
    индекс «тема → записи»;
  - `pairs` — рёбра графа: объединение всех `neighbors`, пара `(a, b)` с `a < b` один раз, вес округлён
    до 3 знаков. У популярной записи рёбер может быть больше 3 — её выбрали другие.
- «Похожие записи» в карточке — все рёбра записи по убыванию веса, до 5.
- `MIN_SIM` — константа модуля, подбирается на живой базе так, чтобы у большинства записей с карточкой было
  1–3 соседа; начальное значение 0,12.

### Проекты — `dashboard.project_key(project) -> (ключ, имя)`

- Последний сегмент пути или репозитория (`~/Documents/vscode/club-landing` → `club-landing`,
  `vladilenm/club_landing` → `club_landing`); ключ — в нижнем регистре, `_` и пробелы → `-`.
- Папки черновиков Claude (`…/scratch-workspaces/…/scratch-…`) — один проект с ключом `scratch`, имя «Черновики».
- Имя проекта — самое частое исходное имя среди записей группы. Совпадение имён у разных проектов склеит их;
  это принимается, на странице проекта видны все пути.

### `dashboard.collect()`

К нынешним полям добавляются:

- у каждой записи `pkey` (ключ проекта) и `topics` (до 8 отображаемых тем);
- `projects` — `{ключ: {"name", "paths"}}`;
- `graph` — `{"edges": [[id_a, id_b, вес], ...]}`.

Подсчёты для плиток и графиков (по неделям, по проектам, по источникам) делает страница, как сейчас.

### Шаблон

- `brain/dashboard.html` заменяется папкой `brain/web/`: `index.html` (разметка), `style.css`, `charts.js`
  (столбцы, полосы, мини-графики, подсказка), `graph.js` (физика и отрисовка графа), `app.js` (данные, вкладки,
  адреса, поиск, карточка записи, вкладки Обзор/Проекты/Записи).
- `dashboard.build()` вшивает CSS в `<style>`, данные и JS — в **один** `<script>` (данные первыми, затем
  `charts.js`, `graph.js`, `app.js`) и пишет один файл, как сейчас. Если в CSS или JS встретится `</`
  внутри строки, сборка падает с понятной ошибкой — иначе страница сломается молча.

## Крайние случаи

- Пустая база: плитки с нулями, графики с приглашением «Запусти `brain sync`», граф пустой с той же подсказкой.
- Нет карточек: связей по темам нет, граф показывает записи вокруг проектов; переключатель «связи по темам»
  неактивен с подписью «появятся после пересказа».
- Источник без записей с `hint` (ChatGPT) — подсказка в здоровье базы, чип в графе с нулём.
- Ошибка источника видна в меню на любой вкладке; прерванный прогон — как сейчас («прервался»).
- Темы: светлая и тёмная по `prefers-color-scheme`; цвета источников заданы парами и проверены валидатором
  палитры (dataviz) для обеих тем:

| Слот | Источник | Светлая | Тёмная |
|---|---|---|---|
| 1 | Claude Code | `#7C3AED` | `#8e72f2` |
| 2 | Codex | `#16a070` | `#199e70` |
| 3 | GitHub | `#eb6834` | `#d95926` |
| 4 | ChatGPT | `#2a78d6` | `#3987e5` |

  Первые три слота различимы всеми парами (граф — «все пары»), четвёртый проходит только соседние пары, поэтому
  в графе источник всегда подписан в подсказке и чипах. Новый источник получает следующий слот; больше восьми
  не будет — сворачиваются в «Другие».
- Мобильная ширина: поле 16px, плитки в две колонки, граф на всю ширину высотой 70vh, щипок и кнопки масштаба.
- Клавиатура: вкладки и строки фокусируемы, `/` — поиск, `Esc` — закрыть карточку или подсказку поиска.

## Не входит

- Живой сервер и поиск BM25 в панели (подход C).
