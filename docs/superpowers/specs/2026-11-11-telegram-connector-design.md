# Источник Telegram: посты своих публичных каналов

Запрос: чтобы нейронки знали, что пользователь публикует в своих Telegram-каналах.
Только публичные каналы; «Избранное» и переписки — отдельная задача (нужна пользовательская сессия).

## Решение

API-коннектор `telegram` читает страницу предпросмотра `t.me/s/<канал>`: без входа, ключей
и внешних библиотек (разбор — `html.parser` из стандартной библиотеки). Отвергнуты Bot API (не отдаёт
историю и требует бота-администратора) и пользовательская сессия (внешняя библиотека и файл с полным
доступом к аккаунту) — сессия понадобится только для «Избранного».

## Запись

Один пост с текстом — одна запись: `source` `telegram`, `external_id` `<канал>/<номер>`, заголовок —
первая строка поста, дата — время публикации, `location` — ссылка на пост, `kind` `document`, без проекта.
Текст: строка «Канал: <название> (@имя)», для пересланных — «Пересланный пост», затем текст поста;
адрес ссылки дописывается в скобках, если его нет в самом тексте. Посты без текста пропускаются.

Не берутся: просмотры и реакции (меняются постоянно и гоняли бы запись на пересказ), имя источника
пересланного поста (Telegram отдаёт его через раз), цитата поста, на который отвечают.

## Обновление

Первый прогон читает историю назад до конца, не больше `max_pages_per_run` страниц за прогон
(около 17 постов на странице), с паузой между запросами. Дальше раз в час перечитываются две свежие
страницы: новые посты и правки недавних. Правки старых постов не подхватываются.
Курсор — JSON `{"канал": {"max": номер, "back": докуда дочитана история}}`.

## Ошибки

Канал без публичной страницы — ошибка источника с именем канала, остальные каналы обрабатываются.
Пустой список каналов и нет связи — ошибка источника.

## Проверка

Тесты на локальном HTTP-сервере: полный первый проход, цитата и пересланный пост, ссылки, пост без
текста, новые посты и правки, продолжение истории после лимита страниц, закрытый канал, сквозная
синхронизация с поиском и отсутствие изменений при повторном прогоне. Пробный прогон реального канала
на временной базе, включая повторные прогоны без изменений.
